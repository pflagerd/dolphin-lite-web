Dolphin Lite Web

A KDE Dolphin–style file explorer · Node.js + Express · Breeze Dark theme
Node.js Express 4 Breeze Dark No build step

Quick Start

1
Run ./setmeup — checks for Node.js and npm, and runs npm install (which includes the local nodemon dev dependency) if needed.
2
Run ./runme [dir] — picks a random port, starts the server with live-reload, waits until it answers, then launches Chrome opened at dir (defaults to the current directory).
3
Browse your filesystem. Edit server.js or index.html and the server restarts automatically.
Project files
File Type Purpose
server.js server Express HTTP server and REST API. Serves index.html and exposes thirteen API endpoints (JSON unless noted): /api/ping (liveness check the page polls so it can close itself if the server goes away), /api/home (the start directory passed by runme, plus the current user name), /api/ls (directory listing with sort and hidden-file support), /api/places (sidebar locations including auto-detected mount points), /api/stat (full metadata for a single path), /api/mkdir, /api/rename, /api/delete, /api/copy, /api/search (recursive filename search up to depth 6), GET /api/watch (Server-Sent Events stream of changes in a folder, via fs.watch), POST /api/shutdown (sent by the page when the window closes; stops the server and its nodemon parent), and GET/POST /api/settings (reads or merges per-directory settings in .dolphin-lite-web.json). Reads PORT from the environment so runme can supply a random port.
index.html client The entire browser-side application — HTML, CSS, and JavaScript in one file. Renders the Breeze Dark UI: toolbar with Back / Forward / Up / Refresh, a clickable breadcrumb bar that switches to an editable path input on click (Ctrl+L), a Places sidebar with section headers and active-item indicator, three view modes (Icons, Compact, Details), inline rename, drag-box multi-selection, a context menu, a Properties dialog, a live search panel, a zoom slider, and a status bar. No framework or build step — runs as plain vanilla JS.
setmeup script One-time (and safe-to-repeat) environment setup. Checks that Node.js and npm are available, runs npm install when node_modules/ is absent or package.json is newer, and reports the version of the locally installed nodemon dev dependency. It does not install anything globally. Always run this first on a fresh checkout.
runme script Development launcher. Usage: ./runme [dir]. The optional dir sets the start directory (defaults to the directory you run it from). Runs setmeup, picks a random port in the range 3000–9999, and reads saved window size and position from .dolphin-lite-web.json in the start directory, if present. It then starts nodemon watching server.js and index.html so the server restarts automatically on any save, polls /api/home until the server answers, and finally launches activity-google-chrome (with google-chrome and chromium-browser as fallbacks) pointed at http://localhost:<port>.
package.json config npm project manifest. Declares the single runtime dependency (express), the nodemon dev dependency, and the npm start script alias for node server.js.
package-lock.json config Locked dependency tree. Guarantees reproducible installs — every npm install resolves to exactly the same versions regardless of when or where it runs. Committed to version control; do not edit by hand.
.gitignore config Git exclusion list. Tells Git to ignore the node_modules/ directory, so the hundreds of dependency files are never committed to the repository, and per-directory .dolphin-lite-web.json settings files.
README.html doc This file. Project documentation styled to match the Breeze Dark aesthetic of the app itself. Open directly in a browser — no server required.
